# Interim Operator Notes

This repository contains working notes, decision memos, and operating artifacts
from interim and transition mandates.

It is not a methodology repository.
It is not a consulting toolkit.

These documents reflect how responsibility is carried
when organisations move through critical transitions
such as market entry, restructuring, or leadership change.

All material is anonymised and written from practice,
not from hindsight.
